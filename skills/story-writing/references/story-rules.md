# 谐音梗故事创作规则

> 基于 28 篇原作（2026-06-23 ~ 2026-07-14）的风格分析

---

## 核心公式

**设计一个场景，让一句字面短句自然、完整且必要地概括故事，而它同时谐音某个常用表达。**

### 贯穿式谐音：小耗子案例

优秀故事不是“前面讲完普通故事，最后贴一句谐音”，而是从第一张图开始就为目标表达逐音节准备素材。项目中的“小耗子”故事可作为标准案例：

| 目标表达 | 字面素材  | 前文承担的作用                                    |
| -------- | --------- | ------------------------------------------------- |
| 好       | 耗子      | 小耗子是全篇主角                                  |
| 想       | 大象      | 大象知道小耗子的愿望并帮助它                      |
| 马上     | 马 / 骑马 | 大象假装成马，让“马上”同时有角色和动作依据        |
| 见       | 箭        | 小耗子贯穿全篇练习、射出弓箭，形成“箭/见”音义关联 |
| 到       | 到        | 箭确实射到了目标位置                              |
| 你       | 泥        | 箭最后掉进泥巴里，泥是情节结果而非临时替换        |

最后的“耗象马上箭到泥”不是新增信息，而是把前文已经发生的角色、动作和结果重新排列，谐音成“好想马上见到你”。创作时必须优先采用这种“先拆表达、再搭情节”的方法。

关键：

- 原表达不限于情话，也可以是日常用语、流行语、情绪、祝福或其他自然表达
- 这个短句是场景中「不得不说出来」的——不能硬凑
- 比如鱼在泥里很开心 → "鱼见泥很开心"（遇见你很开心），这是角色自然会说的话
- 谐音句中的每个实词都必须对应故事里的主角、动作、对象、状态或结果，并且处于同一条因果链
- 不能为了凑谐音临时加入无关角色、物品、动作或设定

## 逐词关联硬标准

创作前先拆解候选落梗。以下五项必须同时通过：

1. **逐词有证据**：每个实词都能指出前文哪一页已经建立；`很久`、`一直`、`特别` 等时间或程度修饰也必须有明确铺垫。
2. **词与词相关**：主角确实执行该动作，动作确实指向该对象，并真实产生该状态或结果。
3. **字面能独立成立**：不知道谐音原句时，这句话仍须符合正常中文语序和搭配，是自然、完整的故事总结或回答。不能因为名词与状态分别出现过，就把它们压缩成一个现实中不会说的短语。
4. **因果能闭环**：条件变化导致结果，落梗句直接解释结果；不能只是一句贴在故事末尾的口号。
5. **谐音须完整**：真正表达的每个关键音节都须在字面句中有清楚对应。不能省略音节，不能把 `哟` 等读音不同的语气词当作缺失音节，也不能靠看到最后一页后反推才能听懂。
6. **前文必须逐音节铺垫**：最终表达里的角色名、物品、动作、地点和结果，都要在前文承担实际情节功能。故事中出现“大象”不能只算出现了“想”，它必须参与“想”的相关行为；出现“箭”也必须真的射箭或落箭，不能只是摆设。
7. **禁止末页贴梗**：如果前文删掉某个物品或角色后，故事仍然完全成立，而该物品只用于最后拼音，则淘汰候选。

用下面的方式自检：

| 谐音词 | 字面身份 | 前文证据         | 与其他词的关系     |
| ------ | -------- | ---------------- | ------------------ |
| 蚝     | 主角     | 生蚝离开泥滩     | 发出“想”的主体     |
| 想     | 情绪     | 离开后闷闷不乐   | 指向原本生活的泥滩 |
| 泥     | 对象     | 生蚝原本住在泥滩 | 回到泥滩后重新开心 |

任何一格无法自然填写，就淘汰候选。

## 两种造梗模式

### 模式 A：评价或现象型 —— 落梗直接描述结果

整个故事用于证明这个评价或现象为什么成立。

| 故事     | 情景                                  | 产生的名字/说法 | 谐音     |
| -------- | ------------------------------------- | --------------- | -------- |
| 蒜你厉害 | 小蒜头赢得蔬菜举重比赛→大家称赞它     | 蒜你厉害        | 算你厉害 |
| 柿不可挡 | 柿子失去阻挡后飞快滚下山坡→谁也拦不住 | 柿不可挡        | 势不可挡 |

**特点**：不一定需要角色对话，也不一定需要动物主角；但落梗中的每个实词仍须共同描述同一个对象或现象。

### 模式 B：情绪或对话型 —— 落梗直接解释角色反应

| 故事   | 情境                                           | 自然说出的话 | 谐音         |
| ------ | ---------------------------------------------- | ------------ | ------------ |
| 鱼见泥 | 鱼在水里失落→放泥里开心→你猜为什么？           | 鱼见泥很开心 | 遇见你很开心 |
| 好想你 | 生蚝离开泥滩后失落→回到泥滩后开心→你猜为什么？ | 蚝想泥呀     | 好想你呀     |
| 我搓啦 | 衣服洗不干净→妈妈说"认真搓"→哭着说             | 我搓啦       | 我错啦       |

**关键**：角色说的这句话，必须是那个场景下合理的回应，不能为了凑谐音硬编。"鱼见泥很开心"解释鱼为什么开心；"蚝想泥呀"解释生蚝离开泥滩后的情绪；"我搓啦"描述角色实际完成的动作。

## 分页文案与画面细节分离

每张图的文字是旁白，不是绘画提示词。旁白可以简短，但必须构成完整情节，让读者只看旁白也能明白角色、动作和结果；通常使用一至两句短句，不设置僵硬字数上限。角色表情、道具、环境和额外搞笑细节可放在画面说明中，但不能把“发现大梨”“一起玩”这类只有标签、没有动作结果的短语当作旁白。小耗子案例中的“它的好朋友大象知道了以后，就偷偷在脚上穿了个蹄子鞋套”就是合适长度：信息完整，同时留出画面表现空间。生成故事时可使用以下格式：

```
[图1] 旁白：小耗子最喜欢射箭
画面：小耗子抱着弓箭，旁边摆着练习用的箭靶，表情认真。
```

不能把旁白和画面说明合并成一大段放到图片文字里。最后两页尤其要短：倒数第二页只放字面谐音句，最后一页只放真实表达。

## 句子关联规则

默认每个故事 8 张图，每张图一句话；根据因果链在 7–9 页内自然调整，不为凑页数添加无关内容。默认结构：

1. 主角或事物登场
2. 原始环境或状态
3. 问题或负面反应
4. 条件发生改变
5. 产生明显结果
6. 提问制造悬念
7. 用完整字面谐音句直接解释结果
8. 揭示对应的真正表达

无论总页数是 7、8 还是 9，最后两页的职责固定：倒数第二页给字面谐音句，最后一页给真正表达。需要缩短时压缩前情，需要扩展时补充真实因果或反差，不能加入与落梗无关的过渡页。

句子之间的关联方式：

1. **因果推进**（最常见的正确写法）

   ```
   鱼在水里失落 → 放泥里就开心 → 为什么？→ 因为鱼见泥很开心 → 遇见你很开心
   ```

   每一句解释上一句的"为什么"，或者引出下一句的"然后呢"。

2. **条件对比**（产生反差→出梗）

   ```
   柿子被石头挡住 vs 石头被吹走 → 飞快滚下山坡 → 柿不可挡
   生蚝在水缸里失落 vs 回到泥滩后开心 → 为什么？→ 蚝想泥呀
   ```

3. **评价生成**（逐层解释评价怎么来的）
   ```
   小蒜头参加举重 → 举起最重的铁锅 → 大家称赞：蒜你厉害
   ```

不要写：

```
从前有只小猪。它喜欢苹果。有一天它去河边玩。看到了小鸭子。（✗ 每句之间没有因果关系）
```

## 角色选取

**不是每篇都需要小动物主角**，根据梗的需要选择：

| 类型           | 适用场景                     | 例子                   |
| -------------- | ---------------------------- | ---------------------- |
| 不需要动物主角 | 梗围绕一个概念、现象或物品   | 柿不可挡（柿子）       |
| 需要角色互动   | 梗来自帮助、冲突、比赛或问答 | 蒜你厉害（蒜头与观众） |
| 一个人就行     | 梗来自个人情绪或行为         | 鱼见泥、蚝想泥、我搓啦 |

## 谐音素材

可作为候选的高频谐音：

- 泥=你、梨=你、饺=觉、碍=爱、搓=错、蒜=算、辣=爱、柚=you、莓=没/每

可探索的新谐音：

- 苹=平、桃=逃、虾=瞎/想、铃=聆、松=松、蕉=交、西=希、奶特=night

素材表只用于发散，不能证明故事成立。每个候选仍须通过逐词关联硬标准；同时避免重复使用 `泥` 和 `梨`。

## 表达类型

| 类型         | 示例                       |
| ------------ | -------------------------- |
| 日常表达     | 算你厉害、势不可挡、放轻松 |
| 情绪与流行语 | 太难了、真开心、问题不大   |
| 祝福         | 平安就好、好事发生         |
| 情话与想念   | 遇见你很开心、好想你       |
| 晚安与道歉   | 睡个好觉、我错啦           |

题材不是验收条件；只要逐词相关、字面成立、因果闭环即可。

## 创作步骤

1. **选表达** → 从日常用语、流行语、祝福、情话或其他自然短句中选择候选
2. **找谐音** → 把候选表达转换为具体主角、动作、对象、状态和结果
3. **逐词建表** → 为每个实词填写字面身份、前文证据和与其他词的关系；填不满就淘汰
4. **倒推场景** → 在什么情境下，有人会自然说出或用这句话解释结果？
   - 问自己：如果现实中遇到这个场景，说"XX"合理吗？
   - 不合理就换场景，不要硬凑
5. **补因果链** → 为了让这个结果出现，需要什么前因和条件变化？
6. **按 7–9 页落稿** → 默认 8 页；倒数第二页必须直接回答前面的提问，最后一页只揭示真正表达

## 示例

**故事名 / 表达**：好想你
→ **谐音**：蚝想泥
→ **逐词关系**：蚝是主角；想是离开后的真实情绪；泥是原本生活且想念的对象
→ **因果**：离开泥滩后失落→回到泥滩后开心→“蚝想泥呀”直接解释反差

```
[图1] 从前有一只住在泥滩里的生蚝
[图2] 有一天它被放进了干净的水缸
[图3] 它却一直合着壳闷闷不乐
[图4] 后来人们把它送回了泥滩
[图5] 它马上开心地张开了壳
[图6] 你猜这是为什么？
[图7] 因为蚝想泥呀
[图8] 因为好想你呀
```
